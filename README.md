# RobotHunter

🎮 [ブラウザでプレイ](https://hachiware2022.itch.io/robothunter)

---

## ゲーム概要
**RobotHunter** は、迫りくる敵や障害物をかわしながら撃破していく3Dアクションゲームです。  
職業訓練校での **チーム制作課題** として開発しました。  

- 横移動のみで操作できるシンプルなアクション性  
- 岩を3回破壊するとボスが出現  
- ボスを撃破すればゲームクリア  

---

## 操作方法
- **← / → 矢印キー** または **A / Dキー**：左右移動

---

## 担当箇所（上野 哲）
チーム制作の中で、以下を主に担当しました。

- 敵キャラクターの作成
- 岩の作成
- ボスキャラクターの作成
- **ObjectGenerator**（オブジェクト生成処理）の実装
- プレイヤーキャラクターの挙動のバグ修正
- プレイヤー弾の当たり判定・エフェクト
- **SoundManager**（BGM / SEコントロール）の作成
- **GameManager**（ゲーム進行管理）の作成

---

## 制作背景
- 使用技術：**Unity / C#**
- チームで企画から実装までを分担し、完成まで取り組みました。  
- 「現状のスキルで作れる3Dゲーム」をテーマに設計し、ゲームとして遊べる形に仕上げています。
